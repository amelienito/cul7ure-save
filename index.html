Brancher le Google Sheet

Le site lit le Sheet de suivi à chaque visite : ce que vous cochez là-bas apparaît ici.

  1. Dans le Google Sheet : Fichier → Partager → Publier sur le Web.
  2. Choisis l’onglet du suivi, puis Valeurs séparées par des virgules (.csv).
  3. Clique Publier, copie l’adresse et colle-la ici.

Enregistré dans ce navigateur seulement. Pour que Florian l’ait aussi sans rien faire, mets l’adresse dans config.js sur GitHub.
