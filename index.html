        Les liens des Docs

        Le script les retrouve tout seul toutes les heures.

        Ouvrir le Sheet
        Installer le script (une fois, sur ordinateur)
        1. , puis ouvre script.google.com et clique Nouveau projet.
        2. Efface tout, colle le script, et enregistre (icône disquette). Nomme le projet « Cul7ure ».
        3. En haut, choisis la fonction installer puis clique Exécuter.
        4. Google demande l’autorisation : choisis ton compte, puis Paramètres avancés → Accéder à Cul7ure (non sécurisé) → Autoriser. C’est ton propre script, Google ne l’a juste pas vérifié.
        5. Le journal affiche l’adresse du Sheet et ton code d’accès.
        6. Déployer → Nouveau déploiement → roue dentée → Application Web. Exécuter en tant que : Moi. Qui a accès : Tout le monde. Puis Déployer.
        7. Copie l’URL de l’application Web, et colle-la ici avec le code.

        Le script cherche les Docs dans le dossier Drive « Cul7ure - Archives ». S’il porte un autre nom, change la ligne var DOSSIER tout en haut du script.
